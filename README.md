# 🚀 Python Web Scraping & Automation Portfolio

A collection of practical Python web scraping and automation scripts built for data extraction, dynamic web rendering, and business lead generation.

---

## 📂 Projects Included

### 1. E-commerce Product Scraper (`ecommerce_scraper.py`)
* **Description:** A static web scraper built using `requests` and `BeautifulSoup` to extract product titles, prices, and availability from e-commerce sites.
* **Output:** Saves the extracted data directly into a clean CSV file (`books_data.csv`).
* **Libraries:** `requests`, `bs4`, `pandas`

### 2. Dynamic & Login Scraper (`dynamic_scraper.py`)
* **Description:** A modern automation script built with **Playwright** to handle JavaScript-heavy dynamic websites and infinite scrolling pages.
* **Libraries:** `playwright`

### 3. Business Lead Generator (`lead_generator.py`)
* **Description:** A utility script designed to collect business categories, mock contact details, and structured data for lead generation purposes.
* **Output:** Exports structured business leads into `generated_leads.csv`.
* **Libraries:** `requests`, `bs4`, `pandas`

---

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Core Libraries:** BeautifulSoup, Playwright, Pandas, Requests
